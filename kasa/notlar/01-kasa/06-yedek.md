# Yedek

Kasanin tamami duz metin: `kasa/notlar/` klasorunu kopyalamak yedek almaktir.
Ozel bicim, veritabani, kilit dosyasi yok.

Bu depo git kullandigi icin notlar zaten surumleniyor:

```
git add kasa/notlar && git commit -m "kasa: notlar"
```

`kasa/harita.html` URETILEN dosyadir. Kaybolursa `python3 src/kasa.py yap`
geri getirir; elle duzenlemenin anlami yok, ilk uretimde ustune yazilir.

Notlari baska bir araca (Obsidian, iA Writer, herhangi bir metin duzenleyici)
tasimak istersen dosyalar oldugu gibi acilir — bas bilgi bicimi ayni.
